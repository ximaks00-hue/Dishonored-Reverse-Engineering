# Build evidence

This directory contains metadata about the local copy only. It does not contain game files. `files.csv` is generated by `tools/inventory.py` and should be regenerated after the installation changes.

The [`uelib-texture-tfc-references.csv`](uelib-texture-tfc-references.csv) table joins UELib `TextureFileCacheName` property values from four owner classes to TFC basenames from the build manifest. See [EXP-0090](../../../experiments/EXP-0090-uelib-texture-tfc-name-joins.md) for counts and limits; the table does not resolve internal TFC entries or runtime use.

The [mip census](tfc-mip-probe-Abbey_01_Keys_SF-key_set_01_d.csv) and [pixel verification](tfc-mip-pixel-verification-Abbey_01_Keys_SF-key_set_01_d.json) record one exact UELib-to-UModel mip match; see [EXP-0092](../../../experiments/EXP-0092-uelib-tfc-mip-byte-to-pixel-verification.md) for limits.

The [second texture mip census](tfc-mip-probe-Abbey_01_Keys_SF-key_set_01_n.csv) and [pixel verification](tfc-mip-pixel-verification-Abbey_01_Keys_SF-key_set_01_n.json) are documented in [EXP-0093](../../../experiments/EXP-0093-second-texture-tfc-mip-pixel-verification.md).

The [CharTextures mip census](tfc-mip-probe-Dishonored_MainMenu_Env-dead_wap_body_01_d.csv) and [pixel verification](tfc-mip-pixel-verification-Dishonored_MainMenu_Env-dead_wap_body_01_d.json) include the two-chunk LZO sample documented in [EXP-0094](../../../experiments/EXP-0094-cross-cache-chunked-lzo-mip-pixel-verification.md).

EXP-0095 records UModel cache selection and the UELib `UnknownObject` limitation for selected `LightMapTexture2D` objects; its console captures remain in ignored extraction storage.

The [LightMap mip ranges](tfc-mip-probe-Dishonored_MainMenu_Env-DirectionalMaxComponent0_3-lightmap.csv) and [pixel verification](tfc-mip-pixel-verification-Dishonored_MainMenu_Env-DirectionalMaxComponent0_3-lightmap.json) use an explicit UELib parser alias; see [EXP-0096](../../../experiments/EXP-0096-lightmap-alias-mip-range-pixel-validation.md) for evidence limits.

The [second-package LightMap audit](tfc-mip-audit-artdealer_large-lightmap.json) and [pixel comparison](tfc-mip-pixel-verification-L_ArtDealer_Block-DirectionalMaxComponent0_1-lightmap.json) are recorded in [EXP-0097](../../../experiments/EXP-0097-lightmap-alias-second-package-validation.md).

The [ShadowMap census](tfc-mip-probe-L_ArtDealer_Block-ShadowMapTexture2D_91253.csv) and [range/format audit](tfc-mip-audit-shadowmap-artdealer.json) are recorded in [EXP-0098](../../../experiments/EXP-0098-shadowmap-uelib-mip-census-umodel-gap.md). UModel reports this class unsupported, so it has no pixel comparison.

UELib reports `Format=PF_G8` for this ShadowMap sample and all 11 decoded mip lengths equal width×height; this remains UELib-only evidence. See [EXP-0102](../../../experiments/EXP-0102-shadowmap-serialized-g8-format.md).

The [second ShadowMap census](tfc-mip-probe-Dishonored_MainMenu-ShadowMapTexture2D_78538.csv) and [PF_G8 audit](tfc-mip-audit-shadowmap-mainmenu.json) extend the property/length result to another package; UModel also rejects this class here. See [EXP-0103](../../../experiments/EXP-0103-shadowmap-second-package-g8-replication.md).

The [TextureFlipBook census](tfc-mip-probe-L_ArtDealer_Block-Txr_FireFlipBook.csv) and [all-mip DXT1 audit](tfc-mip-audit-artdealer-fireflipbook.json) document one additional texture subclass. UModel reports this class unsupported; see [EXP-0104](../../../experiments/EXP-0104-textureflipbook-mip-structural-audit.md).

The census summary JSON also preserves the serialized `HorizontalImages`, `VerticalImages`, `FrameRate`, and `FrameTime` fields for `Txr_FireFlipBook`. These are package values only; playback semantics remain unverified.

The [third-package LightMap census](tfc-mip-probe-L_Boyle_Ext_Env-DirectionalMaxComponent0_10-lightmap.csv), [all-mip audit](tfc-mip-audit-boyle-ext-lightmap.json), and [pixel comparison](tfc-mip-pixel-verification-L_Boyle_Ext_Env-DirectionalMaxComponent0_10-lightmap.json) are documented in [EXP-0099](../../../experiments/EXP-0099-lightmap-third-package-mip-pixel-validation.md).

The [five-object LightMap trailing-region audit](lightmap-trailing-guid-audit.json) checks the repeated 32-byte post-mip range and embedded census GUID words; see [EXP-0100](../../../experiments/EXP-0100-lightmap-trailing-guid-byte-audit.md).

The [DLC05 LightMap census](tfc-mip-probe-L_DLC05_Arena_Env-DirectionalMaxComponent0_10-lightmap.csv), [all-mip audit](tfc-mip-audit-dlc05-lightmap.json), and [pixel comparison](tfc-mip-pixel-verification-L_DLC05_Arena_Env-DirectionalMaxComponent0_1-lightmap.json) are documented in [EXP-0101](../../../experiments/EXP-0101-lightmap-dlc05-cross-cache-pixel-validation.md).
