# Exact-build internal function triage

Generated by [EXP-0072](../../../../experiments/EXP-0072-exact-build-internal-function-subsystem-triage.md) from the exact-build `functions.csv` index and `callgraph.sqlite` export.

- [`internal-function-triage.csv`](internal-function-triage.csv): one row per indexed internal function address with index label family, conservative subsystem-name candidate (if any), exact direct-call role, incoming data-xref count/source PE sections, size bucket, and an explicit `not_reviewed_by_this_triage` marker.
- [`internal-function-triage-summary.json`](internal-function-triage-summary.json): build/hash identity, denominators, call/data counts, label-family/candidate/role combinations, and limitations.

The classifier assigns symbol-name candidates only for narrow observed API-like families. Those labels do not prove implementation ownership or semantics. Most functions remain in an explicit `unknown` subsystem bucket. Callgraph edges are static references, not runtime reachability. The triage is not semantic function review.

Reproduce from repository root:

```powershell
python tools\function_subsystem_triage.py
```
