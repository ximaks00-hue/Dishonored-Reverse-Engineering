# Security and responsible research

This repository documents research; it does not host the game or bypass tools. Do not commit credentials, proprietary SDKs, game executables, protected content, malicious payloads, or another person's private data. Prefer read-only analysis and synthetic parser fixtures.

For a vulnerability in our own scripts, privately contact the repository owner through GitHub profile contact options or GitHub private vulnerability reporting if enabled. Do not publish an exploit before coordinating. We cannot guarantee a response SLA. Issues are appropriate for non-sensitive tool bugs.

Review scripts before running them and use isolated environments when inspecting untrusted game packages or community-provided samples. No contributor should be required to download copyrighted binaries to participate.
