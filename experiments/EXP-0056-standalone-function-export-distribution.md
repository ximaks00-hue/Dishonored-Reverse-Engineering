# EXP-0056 — Distribution of standalone Function export labels across installed UPKs

- Date: 2026-10-27 (Europe/Kiev).
- Build context: Steam app 217980, build 10256413; executable SHA-256 `66443F3D68A6C658B0ED943260C3EB2F4CC9E3400D5809A94D6EC41EB725E17E`, matching [BUILD-STEAM-10256413](../research/builds/BUILD-STEAM-10256413/build.md).
- Scope: query the generated UModel export-label catalog across all 904 package paths and count rows labelled with `object_class='Function'`.
- Exclusions: this counts UModel class labels only; it does not decode bytecode, detect functions serialized inside other objects, or establish behavior. No game launch or binary modification; `_excluded_coop_project/` was not accessed.
- Tools: SQLite 3; [EXP-0053](EXP-0053-all-install-upk-object-catalog.md) catalog generated from UModel x86 SHA-256 `44F8F1DA90A225554338328E1A2B24BE0B166A34CDFBEEB3C81DA9949E7675D0`.

## Procedure

1. Re-read research status, Blink activation graph, and build record; verify the recorded executable hash.
2. Query `knowledge/database/umodel-package-objects.sqlite`, joining `objects.relative_path` to package rows and grouping objects where `object_class='Function'` by full package path.
3. Count total package rows by the two manifest roots: `DishonoredGame/CookedPCConsole/` and `DishonoredGame/DLC/PCConsole/`.
4. Compare the resulting denominator and label distribution with EXP-0053, which records the 904-package UModel `-list` census and per-package count agreement.

Reproduce the core query:

```sql
SELECT relative_path, COUNT(*) AS function_labels
FROM objects
WHERE object_class = 'Function'
GROUP BY relative_path
ORDER BY function_labels DESC;
```

## Observations

- The catalog contains 904 package rows and 2,885,414 export-label rows; EXP-0053 reports all package listing counts match the UModel `-pkginfo` export counts.
- The catalog contains 4,772 rows with class label `Function`, distributed across 8 package paths.
- All 4,772 such rows are under `DishonoredGame/CookedPCConsole/`; the 434 DLC package paths contain zero rows labelled `Function`.

| Package | `Function` label rows |
|---|---:|
| `DishonoredGame/CookedPCConsole/Engine.upk` | 2,936 |
| `DishonoredGame/CookedPCConsole/DishonoredGame.upk` | 981 |
| `DishonoredGame/CookedPCConsole/Core.upk` | 272 |
| `DishonoredGame/CookedPCConsole/GFxUI.upk` | 161 |
| `DishonoredGame/CookedPCConsole/OnlineSubsystemSteamworks.upk` | 161 |
| `DishonoredGame/CookedPCConsole/OnlineSubsystemPC.upk` | 153 |
| `DishonoredGame/CookedPCConsole/GameFramework.upk` | 105 |
| `DishonoredGame/CookedPCConsole/IpDrv.upk` | 3 |

- The four DLC packages separately examined in EXP-0055 also each have zero `Function`-label rows; this query establishes that property for the full 434-package DLC portion of this catalog.

## Interpretation / claims

- **Observed:** in the complete catalog generated by UModel `-list`, standalone exports labelled `Function` occur in 8/904 packages (all eight are in CookedPCConsole); no DLC package is listed with that class label.
- **Unknown:** whether any DLC class/default/unknown-object payload contains UnrealScript bytecode or other function-like data, and whether UModel labels map one-to-one to every serialized object type in every package.
- **Not established:** that DLC has no executable behavior, that native-only code accounts for DLC behavior, or that the 4,772 labels equal the number of callable functions in the executable/game.

## Reproduction and limitations

- Re-run the SQL above against the generated catalog from EXP-0053.
- The SQLite catalog is local and ignored by Git. Portable evidence is the generator, package census, and this experiment; regenerate the catalog if unavailable.
- The result is scoped to the exact installed package set and UModel labeling in EXP-0053; it is not a source-code or bytecode census.
