# EXP-0081 — Wwise unmatched media IDs joined to same-bank event paths

- Date: 2026-10-27 (Europe/Kiev).
- Build context: Steam app 217980, build 10256413; executable SHA-256 `66443F3D68A6C658B0ED943260C3EB2F4CC9E3400D5809A94D6EC41EB725E17E`, matching [BUILD-STEAM-10256413](../research/builds/BUILD-STEAM-10256413/build.md).
- Scope: join the 40 Sound media-source rows with no same-bank DIDX, same-PCK WEM, global WEM, or parsed global DIDX match to the EXP-0078 same-bank event/HIRC/Sound path catalog; preserve counts and structure chains per media source.
- Exclusions: no WEM payload extraction/decoding, no assumption that these sounds are silence or invalid, and no runtime bank-loading, event invocation, or playback claim.
- Inputs: EXP-0077 sound/media joins, EXP-0078 event/HIRC/Sound/media paths, and direct paths under `research/builds/BUILD-STEAM-10256413/`.
- Output: [unmatched media path catalog](../research/builds/BUILD-STEAM-10256413/wwise-unmatched-media-event-paths.csv), generated by [wwise_unmatched_media_paths.py](../tools/wwise_unmatched_media_paths.py).

## Procedure

1. Re-read research status, Blink activation graph, and build record; verify build 10256413 and the recorded executable SHA-256.
2. Select Sound/media rows with no same-bank DIDX match, same-PCK WEM match, global WEM match, or global DIDX-ID match.
3. Join each selected `(source_pck, bank_id, media_source_id)` to EXP-0078 event paths and EXP-0077 direct event paths using exact bank-local keys.
4. Require every selected row to have at least one event path and retain parser `file_id`, `stream_type`, and external-supply fields without assigning runtime semantics.

Reproduce from the repository root in PowerShell:

```powershell
python tools\wwise_unmatched_media_paths.py `
  --build-dir research\builds\BUILD-STEAM-10256413 `
  --output research\builds\BUILD-STEAM-10256413\wwise-unmatched-media-event-paths.csv
```

## Observations

- The input catalog contains 40 unmatched Sound/media rows, 40 distinct media IDs and sound IDs, across 16 PCK banks. All 40 parser rows have `fileID=0`, `StreamType=0`, and `bExternallySupplied=0`.
- All 40 IDs occur in the same bank's expanded event/HIRC/Sound/media path catalog, yielding 79 path rows across 16 PCKs. The rows include 30 `CAkRanSeqCntr > CAkSound`, 23 nested `CAkRanSeqCntr > CAkRanSeqCntr > CAkSound`, 18 `CAkSwitchCntr > CAkRanSeqCntr > CAkSound`, four `CAkLayerCntr > CAkRanSeqCntr > CAkSound`, two `CAkSwitchCntr > CAkLayerCntr > CAkRanSeqCntr > CAkSound`, and two direct `CAkSound` chains.
- Two of the 79 rows are also present in the direct event-to-Sound path catalog; the other 77 reach their Sound through one or more parsed container-child IDs.
- Each row remains unmatched to the inspected media catalogs despite appearing in an event path. This narrows the gap to media resolution/content and runtime conditions; it does not resolve the media payload.

## Interpretation and claim limits

- **Observed:** all 40 unmatched media IDs occur in parser-derived same-bank event paths; the output records the path count, event IDs, and container-type chains for each source sound.
- **Unknown:** whether the zero file/media fields represent intentional no-media objects, omitted/indirect media, parser limitations, or another Wwise representation; whether any listed event is invoked or the bank loaded; payload identity and playability.
- **Limit:** paths are joins of third-party parser fields and explicit child IDs. They establish static catalog co-occurrence and graph connectivity only, not event execution or audible output.
