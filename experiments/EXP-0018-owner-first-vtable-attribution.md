# EXP-0018 — Owner-first attribution of Controller and PowerWheel

**Статус:** запланирован, не выполнен на оригинальном EXE. **Дата:** 2026-10-26.
**Ранее зарегистрированная сборка:** x86 `Dishonored.exe`, SHA-256 `66443F3D68A6C658B0ED943260C3EB2F4CC9E3400D5809A94D6EC41EB725E17E`, image base `0x00400000`. В EXP-0017 повторно подтвердить этот SHA не удалось.

## Задача

Идентифицировать реального владельца и конкретные virtual targets:
- `DishonoredPlayerController.Dis_SelectPower(int _iPower)` — `+0x560`, wrapper `0x009EE630`;
- `DisGFxMoviePlayerPowerWheel.OnSelectionChanged(int _ItemIdx)` — `+0x1F0`, wrapper `0x009F8290`.

## Протокол (read-only)

1. Найти EXE законно полученной копии в контролируемом пути, повторно получить SHA-256, сравнить с Ghidra `Program.getExecutableSHA256()`, базой и x86-архитектурой. Не запускать неизвестные DLL.
2. Сохранить *оба* списка точек входа функций (старый 72 925, новый 72 437) с точной версией/фильтрами Ghidra; сравнить множества entry VA, отличить externals и thunks.
3. Получить все 1 176 оригинальных кандидатов, raw log и точную реализацию `vtable_assignment_scan.py`. Индекс из пяти адресов ниже по истории — лишь производный обзор отчёта.
4. Для Controller и PowerWheel **раздельно** проследить class registration → factory/constructor → vptr assignment → начало таблицы. Проверить переустановку vptr при наследовании; два независимых подтверждения класса обязательны.
5. Снять соотнесённые `table_va`, `slot_offset`, `target_va`, `target_rva`, thunk, raw xrefs, caller context и source hash. Инструмент Ghidra в companion ZIP: `Exp0018CandidateEvidenceExport.java`; его выполнение здесь не проверено.
6. Только после доказательства владельца интерпретировать методы. Для Controller проследить `_iPower`; для PowerWheel — `_ItemIdx`. Не смешивать `24`, `2`, `0`, `1/5` без трассировки преобразований.
7. После появления реального Blink call chain исследовать расчёт допустимой точки и запись новой позиции отдельно от Kismet `OnTeleport_Native`.

- Точный модуль/хеш, два доказанных владельца таблиц, реальные target RVA, синтаксис ABI/call-site и журнал открытых альтернатив;
