## Full-project completion contract

“Full reverse engineering” is an umbrella goal, not a finite analysis result by itself. For this repository, treat it as complete only after the following bounded deliverables are either evidenced or explicitly marked unavailable for the named build. The scope is the locally recorded Steam x86 build 10256413, not every platform, patch, DLC build, or undocumented original source.

1. **Provenance and files:** preserve the build identity and reproducible file inventory; account for install, DLC, localization, configuration, and modded files, with provenance limits stated.
2. **Packages and resources:** map all 904 installed UPKs, with parse/read coverage and failures by package; inspect non-UPK resource/config families and their dependency relations.
3. **Script/object metadata:** produce searchable class, function, enum, struct, default-object, inheritance, and reference catalogs for parsed packages; clearly mark native-only or unavailable bodies.
4. **Native executable:** reconcile all 72,437 indexed internal functions into named/typed subsystem groups or explicit unknown buckets; retain exact-build addresses, cross references, vtable ownership evidence, and confidence.
5. **Runtime behavior:** define a finite list of gameplay/UI/AI/system behaviors for the chosen scope; record repeatable experiments with named starting states, inputs, outputs, and build identity. Runtime work depends on a clean, user-started matching process; preserve the baseline before interpreting behavior.
6. **Cross-layer architecture:** connect package metadata, native paths, assets, configuration, and runtime observations only when evidence establishes the join. Keep unknown and conflicting evidence visible.
7. **Independent reconstruction:** specify and implement only selected behavior with documented inputs/outputs and comparison cases. This is a separate deliverable and does not imply source recovery.

### Completion gates

- Every inventory has a stated denominator and exclusions; no unexplained package family or major install directory is silently omitted.
- Package-info and export-list compatibility is measured across the 904 UPKs, not generalized from DishonoredGame.upk; property, bytecode, and asset-export compatibility are separately reported.
- Native function coverage has a denominator and a reproducible triage policy; any unreviewed functions remain counted.
- Each selected runtime behavior has repeatable observations or an explicit blocker and is not inferred from static code alone.
- Open hypotheses, rejected routes, tool gaps, and build limitations have evidence links and remain searchable.
- The status page reports remaining counts and blockers. Completion means these scoped criteria are met; it does not claim all platforms/builds or unrecoverable source code have been reconstructed.
