## Reading these measures

- Each row has its own denominator and evidence type. Do not combine parser coverage, static joins, function analysis, and runtime behavior into one completion percentage.
- A count of indexed or parsed items does not imply semantic understanding. See the [function evidence model](methodology/function-evidence-model.md).
- Connected service versions can differ from repository source. The Assets MCP process was last observed at version `2.1.0` in [EXP-0122](../experiments/EXP-0122-assets-mcp-dlc-package-path-reprobe.md); current repository source reports `2.2.0`. Verify live health after reload.
