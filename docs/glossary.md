# Glossary

Use these terms consistently. Add Dishonored-specific meanings only when supported by evidence.

| Term | Project usage |
| --- | --- |
| Build | A particular installed/released game configuration, identified by recorded files and hashes. |
| Observation | A result directly captured from a stated procedure and scope. |
| Hypothesis | An unconfirmed explanation that makes a testable claim. |
| Evidence | A traceable artifact or observation supporting or challenging a claim. |
| Package | A game file treated as a package by a named parser; record the parser's interpretation. |
| Export / import | Terms reported by a package parser, with tool and package context recorded. |
| RVA | Address relative to a module image, tied to that exact module's identity. |
| Native function | A function in executable code; names assigned during analysis are provisional unless independently established. |
| Reconstruction | An analyst-created model or implementation based on documented evidence. |
