# Code of conduct

We welcome respectful participation regardless of experience level, background, or preferred reverse-engineering tools. Be constructive and evidence-focused; question claims, not people. Harassment, discriminatory remarks, threats, doxxing, and sharing others' private information are not tolerated.

Maintainers may edit, hide, or remove disruptive material and restrict participation. Report conduct concerns through a private GitHub message to the repository owner, where possible, rather than publishing sensitive details in an issue. Maintainers should acknowledge reports, investigate proportionately, avoid retaliation, and disclose information only as necessary. This is a lightweight community policy, not a promise of a particular response time.
